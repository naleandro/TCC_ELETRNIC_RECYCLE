# TCC_ELETRNIC_RECYCLE
-------------------------
📋 Sobre o Projeto
-------------------

A ideia surgiu da necessidade de encarar um problema real: o descarte incorreto de equipamentos eletrônicos (e a oportunidade de gerar uma potencial renda para a instituição). O Eletronic Recycle nasceu no nosso TCC para transformar essa realidade no ambiente escolar!

Combinamos um sistema web gamificado (onde as turmas acumulam pontos reciclando eletrônicos) a um protótipo de lixeira inteligente com Arduino. Assim, promovemos a conscientização ambiental de forma prática e engajadora, enquanto ajudamos a arrecadar recursos para a escola.

🛠️ Tecnologias e Ferramenta
---------------------
Desenvolvimento Web & Banco de DadosHTML5 & CSS3: Estrutura das páginas e estilização visual das interfaces.

Bootstrap: Framework responsivo para adaptação do layout a telemóveis, tablets e computadores.   

JavaScript: Lógica de navegação no lado do cliente e dinamismo da interface.   

Node.js: Ambiente de execução no servidor para o processamento de regras de negócio e rotas da aplicação.   

MySQL: Base de dados relacional para armazenamento de dados de utilizadores, pontuações do ranking e registos de descarte.

Hardware & IoT (Lixeira Inteligente)Arduino: Microcontrolador responsável por gerir os componentes eletrónicos e executar a lógica da lixeira automatizada.

Sensor Ultrassónico (HC-SR04): Sensor de proximidade para detetar a presença do utilizador e acionar a abertura da tampa.  

Servomotor (SG90): Atuador mecânico para o controlo da abertura e fecho automático da tampa da lixeira.   

C++ / Linguagem Arduino: Código de programação carregado na placa para controlo dos sensores e motores
